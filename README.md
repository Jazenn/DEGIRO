# DEGIRO Dashboard

A sophisticated dashboard for analyzing DEGIRO portfolio data.

The replacement dashboard shell is available at `/dashboard-preview` in development
and production builds. It uses visibly labelled synthetic examples and does not
read portfolio data or save settings. The existing dashboard remains at `/` until
reconciliation and access checks permit cutover. The preview combines an overview
first layout, fixed bottom navigation, and a blue-grey palette; financial features
are connected in subsequent implementation tickets.
